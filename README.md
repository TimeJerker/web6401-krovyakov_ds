# Лабораторная работа №2: Основы HTML и CSS

**Цель работы:** Изучение основ HTML и CSS.  
**Задание:** Разработать многостраничный web-сайт с использованием технологий HTML и CSS.

### Описание проекта
Был разработан сайт туристического агентства "Мир Путешествий".
Проект включает в себя 4 страницы:
- `index.html` — Главная страница с навигацией и баннером.
- `tours.html` — Список туров (реализован в виде таблицы).
- `gallery.html` — Фотогалерея туристических направлений.
- `contacts.html` — Контактная информация.

**Выполненные требования:**
1. Использованы блочные (`div`, `p`, `h1`, `ul`) и строчные (`a`, `span`, `img`) элементы.
2. Подключен внешний CSS-файл (`style.css`).
3. Использовано 3 вида селекторов: по тегу, по классу (`.`) и по ID (`#`).
4. В таблице применено выравнивание по левому, правому краю и по центру с помощью CSS.

# Лабораторная работа №3: Основы JavaScript (Core JS)

**Цель работы:** Изучение базовых конструкций языка JavaScript, работы с функциями, рекурсией, замыканиями и алгоритмами сравнения структур данных.  
**Задание:** Реализовать набор алгоритмических и утилитарных функций согласно техническому заданию и обеспечить прохождение модульных автотестов.

### Описание проекта
В рамках лабораторной работы был реализован модуль `core.js`, включающий в себя решения 10 алгоритмических задач. Код успешно проходит проверку встроенными тестами (Mocha).

**Выполненные задачи:**
1. **Базовые алгоритмы и математика:** Реализованы функции вычисления факториала, N-го числа Фибоначчи и суммы чисел (с использованием как циклов, так и рекурсии). Написана функция генерации массива четных чисел.
2. **Побитовые операции:** Реализованы проверки числа на целочисленность (`isInteger`) и на принадлежность к степени двойки (`isBinary`) с использованием побитовых операторов (`|`, `&`).
3. **Замыкания и функции высшего порядка:** 
   - Написана функция `getOperationFn`, возвращающая новую функцию с инкапсулированным (запомненным) состоянием.
   - Создан настраиваемый и независимый генератор арифметической последовательности `sequence`.
4. **Работа с объектами:** Разработана функция глубокого сравнения объектов `deepEqual`. Реализована рекурсивная проверка вложенных свойств, а также корректная обработка краевых случаев языка JS (сравнение с `null`, строгая типизация, обработка значений `NaN`).
5. **Тестирование:** Настроено локальное окружение (`npm install`) и успешно пройдены все модульные тесты преподавателя (`npm test`).
